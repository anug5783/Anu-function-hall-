# Combined Function Hall Booking Project
Main entry point: index.html

Features: hall booking, Veg/Non-Veg food, guest count, price calculation, payment option, booking ID and booking list.

For Node backend:
cd backend
npm install
npm start

Backend runs on http://localhost:5000.

The root index.html is a simple frontend entry point. The complete Node backend is in backend/.
Bookings are stored in memory in this demo and reset when the server restarts.
